# Разработка дашборда в DataLens для выбора ниши на маркетплейсе (WB)
[Ссылка на дашборд в DataLens](https://datalens.yandex/mtoujoileu5s8)

## Данные
В рамках проекта был предоставлен доступ к ClickHouse с данными из MPStats.

## Задача
Разработать отчет в Яндекс DataLens для выбора перспективной ниши на маркетплейсе Wildberries на основании предоставленных данных.

## Выполнено
Исследовательский анализ данных из MPStats, расчет ранговой оценки ниш по ключевым метрикам, построен дашборд в DataLens для сравнения и выбора перспективных ниш

## Используемый стек
Яндекс DataLens
